# Live-weather-dashboard-using-Power-BI-
This is a live  weather dashboard for three cities, Kolkata, Delhi, and  Noida, using  live weather API. This dashboard contains all weather-related components  like humidity, UV ray count, wind speed. Additionally,  this is  also showing  the time of sunrise and sunset. Additionally,  this provides a proper prediction analysis of rain. 
There is some features of the dashboard which is as follows 
🌦️ Real-time temperature, humidity, UV index, and rainfall chances
🌇 Sunrise and sunset visual indicators
💨 Wind speed and forecast trend line
🏙️ City filters (Delhi, Kolkata, Noida) for instant comparison
🌑 Dark-themed interactive design for better visual contrast
🔧 Tools & Skills Used:
 Power BI | DAX | Power Query | API Integration | Data Modeling | Data Visualization
This project helped me strengthen my skills in data storytelling, API connectivity, and Power BI dashboard design — bridging the gap between data engineering and business insight.
